# The DaiZhiGe Organization · 殆知阁

[中文版](#中文)

---

Welcome to the GitHub organization behind **DaiZhiGe**, a project dedicated to digitizing, proofreading, and publishing classical Chinese texts.

### Our Sites

| Site | Description |
| --- | --- |
| [daizhige.org](https://daizhige.org) | Main site: classical texts and full-text search tools |
| [booksearch.daizhige.org](https://booksearch.daizhige.org/) | Book Search for Chinese books on Wikimedia Commons |
| [sikuquanshu.daizhige.org](https://sikuquanshu.daizhige.org) | Full text of the Wenyuange collection of the *Siku Quanshu* (文渊阁四库全书) |
| [shuowen.daizhige.org](https://shuowen.daizhige.org) | Shuowen Jiezi (说文解字) |
| [daizhige.net](https://daizhige.net) | Backup domain / mirror site |

### About This Organization

This organization is the main development workspace and staging area for DaiZhiGe. New texts, metadata, proofreading work, and related resources are prepared, reviewed, and refined here before they are published on our sites.

### Get Involved

We welcome volunteers. We could use help with:

- Digitization
- Proofreading
- Metadata
- Typesetting
- Automation
- Software development

Browse the repositories, open an issue, or start a discussion to get involved. Every contribution is appreciated.
