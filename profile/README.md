# The DaiZhiGe Organization

Welcome to the GitHub organization behind **daizhige.org**.

This organization serves as the primary development workspace and staging area for content that will eventually be published on **daizhige.org**. New texts, metadata, proofreading, and related resources are prepared, reviewed, and refined here before release.

We welcome volunteers to contribute. Whether you are interested in digitization, proofreading, metadata, typesetting, automation, or software development, your help is greatly appreciated. Please explore the repositories, open issues, or start a discussion if you'd like to get involved.
